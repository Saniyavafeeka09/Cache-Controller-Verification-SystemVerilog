# Waveforms

This folder contains simulation waveforms generated during verification of the Direct-Mapped Cache Controller.

The waveforms demonstrate the following cache operations:

- Reset operation
- Cache Read
- Cache Write
- Cache Hit
- Cache Miss
- Address decoding (Tag and Index)
- Write-back policy
- Write-allocate policy

The waveforms were generated using QuestaSim and viewed using EPWave.
